# Security policy

## Supported version

The current release on the default branch is supported with security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through the repository's **Security → Report a vulnerability** flow. Do not open a public issue for a suspected vulnerability and do not include credentials, private data or exploit details in public discussions.

Include the affected version, a concise reproduction, the expected impact and any suggested mitigation. We will acknowledge a complete report as soon as practical and coordinate disclosure after a fix is available.

This public server is intentionally read-only and requires no credentials. Reports concerning private systems, private endpoints or third-party accounts are outside this repository's scope and should not contain their details.
